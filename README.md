# AncestorGFN

**Evolutionary Sequence Design with GFlowNets**

[Read the paper](https://www.biorxiv.org/content/10.64898/2026.04.08.717239v1.full.pdf) · ICLR 2026 Workshop on Generative Models for Genomics

AncestorGFN explores GFlowNet-based RNA sequence generation using LET-7 family sequences as a case study.

![Sequence construction flow network](assets/flow_network.png)

This repository contains the public project overview. The implementation, ongoing experiments and research discussions are maintained privately.
