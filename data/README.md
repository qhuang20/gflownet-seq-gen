# Example data

These files are restored from the earlier public project snapshot:

- `targets_10bp.json`: synthetic 10-symbol RNA targets.
- `LET7_22bp_targets.json`: named LET-7 sequences used in the original examples.
- `LET7_family_mature_ALLspecies.fa`: the original LET-7 family FASTA input.

They are example inputs, not new experimental measurements. The original repository did not record a database release or retrieval date; establish those before using these copies for a reproducible biological study.

Additional original inputs include LET-7 10bp targets, P2b3 subtree sequences, and FASTA/JSON variants used by the historical notebooks.
